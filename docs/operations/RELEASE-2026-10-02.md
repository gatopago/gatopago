## Withheld and incomplete

Dashboard production publication is withheld. It still calls removed
`/auth/email-code/*` endpoints and offers Google-provider Firebase sessions.
Wallet Core V3 admits passkey-backed custom sessions with credential/access
claims; replacing an API hostname alone cannot fix that mismatch. Dashboard's
API defaults, CSP and site links also retain Parmelia hosts. No bypass of Wallet
Core session checks is an acceptable deployment fix.

The runtime still has no paymaster. Test ETH funding and an actual passkey-driven
Arbitrum Sepolia account/USDC-transfer acceptance run remain outstanding:
creation, inclusion/finality, balance reconciliation, safe reservation release
and receipt, including reload and lost-submit-response cases. Public health,
builds and synthetic browser tests are not substitutes. Backup signer activation
and independent exit also remain outside the connected consumer release.
